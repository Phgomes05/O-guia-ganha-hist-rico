# Guia de Locais e Eventos — São Paulo

Projeto acadêmico de desenvolvimento front-end com HTML e CSS.

## Estrutura

- `INDEX.HTML` — página inicial do guia.
- `DETALHE.HTML` — página de detalhe da Neo Química Arena.
- `ESTILO.CSS` — estilos, responsividade e acessibilidade.
- `img/` — imagens utilizadas pelo guia.

## Objetivo

Organizar locais e eventos de São Paulo em uma interface responsiva, com navegação semântica e recursos básicos de acessibilidade.
